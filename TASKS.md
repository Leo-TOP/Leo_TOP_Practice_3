# Задания 01–10. Оживляем афишу мероприятия

Это учебная лестница, а не гонка на скорость. Начните с 01 и двигайтесь по порядку. Если JavaScript для вас новый, первые задания дадут всю необходимую опору. После каждого шага **сохраните файл, проверьте страницу в браузере и попробуйте объяснить результат**.

На семинаре достаточно добраться до 01–05; 01–08 — хороший результат. Задания 09–10 рассчитаны на тех, кто успевает быстрее, и могут быть продолжены после занятия.

## Перед началом

1. Откройте папку проекта в VS Code.
2. Запустите `index.html` через Live Server. Если он не установлен, откройте файл в браузере и обновляйте страницу вручную.
3. Откройте рядом `script.js` и инструменты разработчика браузера: вкладку **Console**. Ошибка в консоли — подсказка, а не повод начинать проект заново.
4. Убедитесь, что видны три карточки, панель «Выберите событие» и учебная подпись «Начните с задания 01». Верстка уже готова: сейчас работаем главным образом с JavaScript.

ТЗ для первой версии: после клика панель показывает данные выбранного события; выделена только одна карточка; при смене карточки меняются текст и акцент. Анимация лишь помогает заметить изменение. Формы, хранилища и запросы к API здесь не нужны — это темы следующих семинаров.

## Группа А. Основы JavaScript

### Задание 01. Первый работающий клик

**Учебный опыт.** В `script.js` уже есть почти готовый обработчик первой карточки. Уберите строки `/*` и `*/` вокруг него. Сохраните файл, обновите страницу и нажмите «Город в деталях». Посмотрите, какая подпись изменилась.

**Практика.** Замените текст в кавычках на собственную короткую фразу: «Открыта первая карточка». Больше ничего пока не меняйте.

**Проверка.** До клика видна исходная учебная подпись, после клика — ваша фраза. В консоли нет красной ошибки.

**Скажите себе:** что здесь является событием, а какие строки выполняются только после него?

### Задание 02. Значение и переменная

**Учебный опыт.** `const` хранит значение, которое вы не собираетесь переназначать. `let` подходит для значения, которое меняется. Заведите название первой карточки и счетчик нажатий:

```js
const eventName = "Город в деталях";
let clickCount = 0;
```

**Практика.** Замените обработчик из 01, не создавая второй обработчик для той же карточки. В этом фрагменте пропущено одно число:

```js
firstCard.addEventListener("click", () => {
  clickCount = clickCount + ___;
  labStatus.textContent = `${eventName}: нажатий ${clickCount}`;
});
```

Сначала подумайте, какое число нужно подставить. Вставляйте фрагмент в `script.js` уже **без** `___`.

**Проверка.** Нажмите первую карточку дважды. Число в подписи должно последовательно стать 1 и 2. После обновления страницы оно снова начинается с нуля.

### Задание 03. Условие

**Учебный опыт.** `if` выбирает, какой код выполнить. После увеличения `clickCount` сравните его с числом первого нажатия. Внутри прежнего обработчика вместо одной строки с подписью используйте такую конструкцию:

```js
if (clickCount === ___) {
  labStatus.textContent = `Первое открытие: ${eventName}`;
} else {
  labStatus.textContent = `Повторное открытие: ${eventName}`;
}
```

**Практика.** Заполните пропуск. До проверки предскажите текст после первого и второго клика.

**Проверка.** Два последовательных клика дают разные подписи. Обновление страницы возвращает поведение к первому клику.

## Группа Б. JavaScript и страница

### Задание 04. Найти элемент и изменить текст

**Учебный опыт.** В `index.html` найдите заголовок панели подробностей. У него есть `id="details-title"`. Метод `document.querySelector(...)` находит элемент по CSS-селектору; `textContent` меняет его обычный текст.

**Практика.** Перед обработчиком создайте переменную. Вместо `___` впишите селектор заголовка:

```js
const detailsTitle = document.querySelector("___");
```

В обработчике первой карточки после изменения подписи добавьте строку, которая записывает `eventName` в `detailsTitle.textContent`.

**Проверка.** Клик по первой карточке меняет заголовок панели на «Город в деталях». Если в консоли написано, что у `null` нет свойства `textContent`, перепроверьте селектор и `id` в HTML.

### Задание 05. Еще один обработчик события

**Учебный опыт.** Посмотрите на обработчик первой карточки, который вы меняли в заданиях 01–04. В записи `element.addEventListener("click", handler)` элемент — это то, на что нажимают, `click` — название события, а `handler` — код ответа.

**Практика.** Найдите вторую карточку и подключите ее к панели. Заполните пропуск в названии события и допишите изменение заголовка:

```js
const secondCard = document.querySelector('[data-event="workshop"]');

secondCard.addEventListener("___", () => {
  // Здесь измените detailsTitle.textContent.
});
```

**Проверка.** Первая карточка показывает «Город в деталях», вторая — «Мастерская постеров». Если работает только первая, проверьте селектор второй и название события.

**Контрольная точка.** Покажите в своем коде: где найден элемент, где зарегистрирован клик, где изменен текст. Если пока не можете, задержитесь здесь и разберите эти три строки.

## Группа В. Несколько карточек

### Задание 06. Массив и коллекция элементов

**Учебный опыт.** Временно добавьте в `script.js` и посмотрите результат в консоли:

```js
const names = ["Город в деталях", "Мастерская постеров", "Звук после заката"];
console.log(names[1]);
console.log(names.length);
```

Массив хранит несколько значений. Индекс первого элемента — `0`. После опыта удалите эти строки: названия уже есть в HTML, и второй список проекту не нужен.

**Практика.** `querySelectorAll` возвращает коллекцию элементов страницы. Найдите все карточки и выведите их количество в элемент `#event-count`:

```js
const cards = document.querySelectorAll("___");
const eventCount = document.querySelector("#event-count");
eventCount.textContent = cards.length;
```

**Проверка.** Над карточками видно «3 события». В консоли нет ошибок. Коллекция из DOM похожа на массив тем, что у нее есть элементы и длина, но это не обычный массив.

### Задание 07. Одно действие для всех карточек

**Учебный опыт.** `forEach` выполняет действие для каждого элемента найденной коллекции. Попробуйте фрагмент ниже. В нем **намеренно допущена одна ошибка в имени переменной**:

```js
cards.forEach((card) => {
  eventCard.addEventListener("click", () => {
    labStatus.textContent = "Нажата карточка из программы";
  });
});
```

**Практика.** Найдите и исправьте ошибку. Пока не удаляйте старые обработчики: они меняют другие части страницы. Общий обработчик из этого задания нужен только для учебной подписи.

**Проверка.** После клика по любой из трех карточек меняется подпись «Лаборатория JS». Если код не запускается, прочитайте в консоли имя переменной, которую браузер не знает.

## Группа Г. Функция и данные

### Задание 08. Одна функция вместо трех копий

**Учебный опыт.** Функция `showEvent(card)` получает карточку как аргумент. Атрибут `data-title` из HTML доступен как `card.dataset.title`, `data-description` — как `card.dataset.description`, `data-time` — как `card.dataset.time`.

**Практика.** Найдите в HTML `#details-description` и `#details-time`. По образцу задания 04 создайте для них переменные `detailsDescription` и `detailsTime` через `document.querySelector(...)`. Затем начните функцию с такого фрагмента:

```js
function showEvent(card) {
  detailsTitle.textContent = card.dataset.title;
  detailsDescription.textContent = card.dataset.title; // Здесь намеренная ошибка.
  // Допишите время события.
}
```

Исправьте ошибку с описанием, допишите время и вызывайте `showEvent(card)` в общем обработчике из 07. Удалите временные обработчики первой и второй карточек и ненужные переменные из 01–05, чтобы на один клик не приходилось несколько независимых ответов.

**Проверка.** Нажмите A → B → C. В панели каждый раз должны совпадать название, описание и время выбранной карточки. В `script.js` остался один общий путь обработки клика.

**Контрольная точка.** Объясните, откуда функция получает данные и почему она работает для всех трех карточек без трех копий кода.

## Группа Д. Состояние и оформление

### Задание 09. Видно, что выбрано

**Учебный опыт.** В `styles.css` найдите `.event-card--selected`, `@keyframes card-arrive` и переменную `--accent` у `.details-panel`. Посмотрите, какие части оформления уже готовы. JavaScript должен лишь выбрать, **когда** применять это оформление.

**Практика.** Доработайте `showEvent(card)`:

1. Храните ссылку на выбранную карточку в переменной `let selectedCard` (сначала там `null`).
2. Если карточка уже была выбрана, уберите у нее класс `event-card--selected`.
3. Добавьте этот класс новой карточке и обновите `selectedCard`.
4. Найдите панель `#event-details` и задайте ей `--accent` из `card.dataset.accent` через `style.setProperty`.

Здесь уже нет готового блока кода. Нужные методы: `classList.remove`, `classList.add`, `style.setProperty`. Анимация в CSS начнет работать при добавлении класса. При желании измените ее длительность и посмотрите разницу. Не удаляйте правило `prefers-reduced-motion`.

**Проверка.** Нажмите A → B → A. Выделена только последняя карточка; цвет акцента панели соответствует ей; выбранная карточка кратко анимируется. Попробуйте пройти по карточкам клавишей `Tab` и нажать `Enter` или пробел.

## Группа Е. Самостоятельный перенос

### Задание 10. Кнопка «Удиви меня»

**Требование.** Кнопка должна случайно выбирать **другое** событие, не то, которое выбрано сейчас. После выбора меняются название, описание, время, выделение, акцент и анимация. Если до этого ничего не выбрано, подойдет любое событие.

**Практика.** Уберите `disabled` у кнопки в `index.html`. Дальше готового JS нет: продумайте действие, при необходимости найдите в документации [`Math.random()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/random) и [`Math.floor()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/floor). Используйте уже написанную `showEvent(card)`, а не создавайте второй способ обновлять панель.

**Проверка.** Нажмите A, затем «Удиви меня»: не должно снова выбираться A. Повторите несколько раз. После каждого выбора текст, класс и цвет говорят об одном и том же событии. Кнопка работает и при нажатии с клавиатуры.

**Вопрос для себя:** что произойдет, если случайный индекс все-таки укажет на уже выбранную карточку? Как код получит другой вариант?
